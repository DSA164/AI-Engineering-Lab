# 🧭 Parcours autonome — AI Engineering

Cette section complète les projets pratiques de **AI-Engineering-Lab** avec un parcours destiné à construire les connaissances nécessaires pour développer progressivement un second cerveau local et une architecture agentique de manière autonome.

## Format de chaque cours

Chaque module contient au minimum :

- `cours.md` — fiche visuelle de synthèse : concepts, modèles mentaux, erreurs rencontrées, architecture et mémo.
- `exemple_complet.py` — programme pédagogique complet et abondamment commenté, destiné surtout à **lire la syntaxe complète sur GitHub**.

Le fichier Python n'est pas nécessairement une implémentation de production. Il sert de référence durable après le cours.

## Code visuel des fiches

- 🔵 **CONCEPT** — nouvelle notion
- 🟢 **À RETENIR** — essentiel
- 🟠 **ARCHITECTURE** — lien avec le système final
- 🔴 **PIÈGE / ERREUR** — erreur rencontrée
- 🟣 **MODÈLE MENTAL** — représentation conceptuelle
- ⚙️ **CODE** — implémentation
- 🧪 **TEST / DÉBOGAGE** — vérification
